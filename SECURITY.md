# Security policy

Treso keeps all data on the phone and has no server. Security issues are most likely in how the app stores data or reads files, such as importing a backup.

## Report a vulnerability

Don't open a public issue. Use [Report a vulnerability](https://github.com/lucien-loua/treso/security/advisories/new) in the repository's Security tab: only the maintainer sees the report.

Include the app version (Settings › About), the phone and system version, and the steps to reproduce. Never attach a real backup or export: it contains someone's financial history.

## Supported versions

Security fixes go into the latest release only.
